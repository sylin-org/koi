## [Unreleased]

### Changed

- Documentation now leads with the container-to-LAN task: label a container, open
  its application from another computer, and keep naming/state correct through
  lifecycle changes.
- ADR-046 and Epic 004 establish an operator preview followed by a trusted-service
  extension, with exact artifact evidence and independent user trials.
- Current documentation separates implemented capabilities, incomplete setup
  workflows, installable channels and scenario acceptance.
- Contributor/fleet entry points use one current epic and ledger. The default
  AI documentation bundle excludes research and retired navigation material.

These changes update documentation and its distribution tooling; they do not
claim new runtime functionality or release acceptance.

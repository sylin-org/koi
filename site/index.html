Koi — Find. Trust. Connect.

An open-source local connectivity substrate: discover services and devices on your LAN, give them short-lived mTLS identities, and connect them — with one small daemon and zero cloud.

Install

macOS & Linux
curl -fsSL https://sylin.org/koi/install.sh | sh

Verifies the archive checksum, installs koi onto your PATH (per-user by default), and shows the next commands. Nothing is auto-started.

Windows (PowerShell)
irm https://sylin.org/koi/install.ps1 | iex

Same contract: checksum-verified archive, per-user PATH install. To run as a background service afterwards: koi install from an elevated shell.

Run it

See your networkkoi mdns discover instant, no daemon needed
Start the daemonkoi serves mDNS, DNS, health, proxy on your LAN
Install as a servicekoi install systemd (Linux) or SCM (Windows, elevated)

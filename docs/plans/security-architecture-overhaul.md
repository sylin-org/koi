# Security architecture

[ADR-011](../adr/011-security-architecture-overhaul.md) records the security
architecture decision. The current [security model](../reference/security-model.md),
[route/auth matrix](../reference/http-route-auth-matrix.md), and
[implementation contract](../../fleet/CONTRACT.md) define operational boundaries.

Current implementation and verification work is selected by
[Epic 004](../../fleet/epics/004-container-lan-adoption.md) and recorded in
[the launch ledger](../../fleet/launch/LEDGER.md).

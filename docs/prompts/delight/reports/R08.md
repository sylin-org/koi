## Plan / exact owner and changed files

- koi-common/src/service.rs and koi-compose/src/catalog.rs: additive explicit local
  device identity, without parsing opaque IDs or guessing hostname correlation.
- koi-ui/src/devices.rs (new pure projection), screens/devices.rs, lib.rs, home.rs:
  device identity/counts, links to existing service details, peer selection and
  explicit comparison states. assets/refresh.js owns only transport/DOM mechanics.
- koi-client/src/comparison.rs (new HTTP reader): bounded read of the existing
  /v1/mdns/snapshot route, no local token on peer requests, no redirects.
- desktop src/comparison.rs (new native adapter) and src/ui.rs: one bounded in-memory
  comparison run, explicit action, concurrent local/peer reads, retained result.
  ui/index.html and ui/app.js move legacy Diff into the shared Devices panel.
- Controlled tests cover equal/different results, missing evidence, incompatible
  query coverage, timeout, refused authorization, and stable device/service links.

Scope is each observer’s active mDNS .local query coverage. Physical interface and
same-network equivalence are not exposed by this API and will not be invented.
Unknown/unavailable coverage is incomplete; equal query coverage permits a bounded
snapshot comparison, never a claim that the whole network or reachability agrees.

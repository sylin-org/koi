# Execution reports

Create reports only when an R task or slice actually runs. Use the template in
[CHARTER.md](../CHARTER.md). Name a file Rxx.md or Rxx-subrow.md and link it from
[LEDGER.md](../LEDGER.md). Keep plans, checkpoints and results in that one report.

Native artifacts, two-sided peer observations and restoration facts remain in the
existing owned fleet journal; link them instead of duplicating raw machine state.
Do not commit secrets, private addresses, invitations or household screenshots.

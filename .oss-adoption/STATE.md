# OSS adoption direction

Koi is an open-source solution for container/LAN developers and capable homelab
operators. [ADR-046](../docs/adr/046-container-lan-adoption.md) is accepted.
[Epic 004](../fleet/epics/004-container-lan-adoption.md) and
[the ledger](../fleet/launch/LEDGER.md) own execution and progress.

The target is label → real second-device application → correct lifecycle.
A bounded operator preview precedes the trusted-service extension. Early
independent observation and retained use guide scope.

Use users, operators, adopters, contributors and maintainers in public language.
No commercial sales model is assumed. The owner authorized the realignment
toward release; prepare and verify concrete artifacts before publication.
Sending messages to people or communities needs explicit communication authority.

Dated channel research, ecosystem research and readiness audits in this directory
remain evidence for their stated dates. Current plans and claims point to the
canonical launch documentation rather than duplicating campaign history.

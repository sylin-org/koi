## Non-claims and known limits

- Koi is not claimed to be production-ready, load-bearing, enterprise-ready, highly
  available, or covered by an uptime/support SLA.
- A passing three-OS `cargo test` matrix is not a passing CI workflow: dependency audit
  failed, and scheduled QA is independently red.
- Release checksums provide corruption detection; provenance attestations provide a
  verifiable build assertion. Neither proves the absence of vulnerabilities or operational
  defects.
- Sealed v0 is not encryption. CA-key encryption at rest does not imply message,
  management-traffic, token, or whole-data-directory encryption.
- Off-loopback management HTTP is not confidential against a network observer unless the
  operator adds a secure transport.
- Runtime event observation is not gap-free convergence or exactly-once delivery.
- Label parsing, an HTTP-SD JSON shape, an ACME route, or a split-DNS recipe is not by itself
  proof of workflow compatibility with Traefik, Caddy, Prometheus, Tailscale, Headscale,
  lego, or certbot.
- A configured embedded data directory is not yet a complete filesystem-isolation
  boundary.
- This audit did not independently execute remote install scripts, verify every attestation
  as a clean consumer, benchmark performance, or observe third-party production use.

# Adoption objective

Koi's focused direction is accepted in [ADR-046](../../docs/adr/046-container-lan-adoption.md).

Deliver a container-to-second-device workflow with correct lifecycle behavior,
put a bounded tested preview into operators' hands, and measure whether it
removes recurring work. Add exact-name HTTPS and one complete proxy/resolver
integration as the next milestone when evidence supports that investment.

Use [readiness](../../docs/launch/README.md), [Epic 004](../../fleet/epics/004-container-lan-adoption.md)
and [the ledger](../../fleet/launch/LEDGER.md) for current facts and work.
The [assessment](../../docs/assessment/2026-09-12-viability-desirability-traction.md)
provides the research basis. Documentation completion is not release or adoption
evidence.
